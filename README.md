# vitorebatista/tap

Homebrew tap for [AeroSpace-edge](https://github.com/vitorebatista/AeroSpace-edge), a maintained fork
of [AeroSpace](https://github.com/nikitabobko/AeroSpace).

```bash
brew install --cask vitorebatista/tap/aerospace-edge
```

Builds are ad-hoc signed, so macOS revokes the Accessibility grant on every install and upgrade —
re-enable AeroSpace-edge in **System Settings → Privacy & Security → Accessibility** afterwards.

`Casks/aerospace-edge.rb` is generated by `script/build-brew-cask.sh` in the AeroSpace-edge repo.
Don't hand-edit it.
